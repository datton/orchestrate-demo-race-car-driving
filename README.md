# Race Car Driving

A small static two-page site about race car driving, built by the Orchestrate Solutions team.

## Pages
- `index.html`: home page, overview of the sport
- `pages/techniques.html`: driving techniques

## Layout
- `css/tokens.css` (Designer), `css/layout.css` (UI/UX), `css/site.css` (Lead Dev)
- `js/app.js` (Full-Stack), `js/nav.js` (UI/UX)
- `assets/`: original SVG illustrations

Plain HTML, CSS and JavaScript. No build step.
